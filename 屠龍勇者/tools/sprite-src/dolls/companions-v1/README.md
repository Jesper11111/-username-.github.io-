原本三款＋使用者新圖18款不重複角色，共21款。白虎選第三張參考圖下方全身版；不另做上方重複白虎。名稱暫作外觀識別，品質已依使用者名單設定T0～T4（見下表）；能力／等級／消耗／取得方式待決定。

## 範圍

僅製作透明外觀與基礎行走／飛行分鏡，不加入正式召喚、背包或存檔。遊戲玩法與script載入順序不變；預覽JS修改依規則同步版本20261024b，SW不預載。預覽頁不載入遊戲程式、不存檔、不連雲端。

## 來源與規格

- reference-1.png：10款奇幻動物；reference-2.png：原三款；reference-3.png：8款神獸／饕餮（白虎去重）。
- plan.json：21款清單與外觀重點，quality為指定T0～T4、effects為null。
- sources/：內建image_gen逐款生成原稿；冰霜幼龍沿用本對話已驗證原稿。
- prompts/：各款完整生成提示詞與原始輸出路徑。
- prepare.py：Pillow打包、共同尺度／腳底定位、透明留邊、12格不重複及逐格圖集比對。
- 格256×240、foot[128,200]、charH160、drawH24；每款正面／右側／背面各4格，145ms／格，左側鏡像右側，停止用中間一格。
- 正式素材：images/sprites/dolls/companions-v1/<id>/，含walk.png、WebP、12單格、contact及manifest；總manifest與catalog.jpg位於同層。

## 預覽

開啟 tools/magic-doll-preview.html，可切換21款、正／右／背／左、播放／暫停／逐格，並在現有遊戲截圖上看約角色一半高的比例。放大2／4倍只供檢查外觀，不代表正式大小；preview-base.png為隔離測試角色畫面。

執行：使用支援Pillow的Python執行本資料夾prepare.py。來源不齊時列出missing，不能把部分結果稱為全套完成。修改／完成後更新HANDOFF.md與ARCHITECTURE.md第115節。
