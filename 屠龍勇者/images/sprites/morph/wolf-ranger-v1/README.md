# 巡守妖魔神射（藍變）：動畫素材 v1

2026-10-22，以使用者提供的原創人物立繪為參考，由內建 image_gen 生成並重製方向／動作。這是一套待驗收的變身動畫素材，尚未接入遊戲的變身選單、變身數值或存檔。

## 檔案

| 動作 | PNG 圖集 | 每方向格數 | 每格時間 |
|---|---|---|---|
| 走路 | walk.png | 4 | 130ms |
| 射箭 | attack.png | 4 | 140ms |
| 施法 | cast.png | 2 | 220ms |
| 受傷 | hit.png | 2 | 150ms |

- 共 36 張獨立透明 PNG，位於 frames/；contact.png 是全部分鏡總覽。
- 每格 256×240，RGBA 真透明；圖集由上而下為 down（正面）、right（右側）、up（背面）。左側使用 right 水平鏡像，裝飾也會跟著鏡像。
- charH＝160；所有動作共用腳底基準 (128,200)，下方留 40px 給向下箭光。未使用補間、交叉淡化或重複分鏡增加格數。
- PNG 是正式素材；*-preview.webp 只供輕量預覽。兩格施法／受傷屬基礎動作，若需更細緻動態，可再增加中間姿勢。
- manifest.json 記錄圖集格數、方向、時間、原稿裁切範圍及腳底位置。

## 後續接入注意

目前人物 renderer 把「整格底端」當腳底。本素材保留弓箭下方空間，接入變身時必須採用 footAnchor：比例 k＝畫面人物高度／160，每格左上畫在 (玩家腳底X−128k, 玩家腳底Y−200k)，不可直接用 cellH 當腳底，否則會浮空。

站立可先停在走路格；受擊及施法按事件播放，播完回到待機／走路。未提供死亡、八方向或不鏡像的左右非對稱動作，這些不屬於本次 36 格規格。

## 來源及重製

參考立繪、八份生成原稿、提示詞、整理腳本在 tools/sprite-src/morph/wolf-ranger-v1/；原始圖不覆寫。prompts.json 記錄第一版提示詞，refinements.json 記錄修正版提示詞與最終選用。prepare.py 只做透明連通區分格、等比縮放、腳底對齊及圖集打包，不合成新的肢體動作。同一動作／方向共用固定縮放，保留姿勢本身的高低變化。
